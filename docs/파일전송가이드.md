# 📤 Ubuntu 서버로 파일 전송 가이드

## 방법 1: PowerShell에서 직접 전송 (추천) ⭐

### 1단계: SSH 키 파일 위치 확인

AWS Lightsail에서 다운로드한 키 파일을 찾으세요:
- 보통 `C:\Users\Choijay\Downloads\` 폴더에 있습니다
- 파일명: `default-key-seoul.pem` 또는 비슷한 이름

### 2단계: PowerShell 열기

현재 폴더에서 PowerShell을 열거나:
```powershell
cd C:\Users\Choijay\Desktop\React\Stock_check
```

### 3단계: 파일 전송 명령어 실행

**PowerShell에서 한 줄씩 실행:**

```powershell
# SSH 키 파일 경로 (실제 경로로 변경하세요)
$keyPath = "$env:USERPROFILE\Downloads\default-key-seoul.pem"
$server = "ubuntu@13.125.123.62"

# 필수 파일 전송
scp -i $keyPath server.py $server:~/
scp -i $keyPath dashboard_modern.html $server:~/
scp -i $keyPath fetch_erp_stock.py $server:~/

# 선택 파일 (있는 경우)
scp -i $keyPath stock_data.json $server:~/ 2>$null
scp -i $keyPath stock_data.csv $server:~/ 2>$null
```

**또는 한 번에 전송:**

```powershell
$keyPath = "$env:USERPROFILE\Downloads\default-key-seoul.pem"
$server = "ubuntu@13.125.123.62"

scp -i $keyPath server.py dashboard_modern.html fetch_erp_stock.py $server:~/
```

## ⚠️ 문제 해결

### "scp가 인식되지 않습니다" 에러
Windows 10/11에는 기본적으로 scp가 포함되어 있습니다. 없다면:

1. **OpenSSH 클라이언트 설치:**
   - 설정 → 앱 → 선택적 기능 → OpenSSH 클라이언트 설치

2. **또는 WinSCP 사용** (방법 2)

### "Permission denied" 에러
SSH 키 파일 권한 문제:

```powershell
# PowerShell에서 실행
icacls "$env:USERPROFILE\Downloads\default-key-seoul.pem" /inheritance:r
icacls "$env:USERPROFILE\Downloads\default-key-seoul.pem" /grant:r "$env:USERNAME:(R)"
```
