현재 **두 가지 방법**이 혼재되어 있습니다:

### 방법 1: Cloudflare Page Rules (권장) ⭐
- **장점**: 서버 부담 없음, 관리자 권한 불필요, 안정적
- **단점**: Cloudflare 설정 필요
- **설정 위치**: Cloudflare → Rules → Page Rules
- **필요한 규칙**:
  ```

  Setting: Forwarding URL (301)
  Destination: http://otinventory.com:18273/$1
  ```

### 방법 2: redirect_server.py (현재 코드에 포함)
- **장점**: 코드로 제어 가능

- **파일**: `redirect_server.py`

## 🚨 현재 문제 가능성

### 1. DNS가 아직 전파 안 됨 (가장 가능성 높음)
- **증상**: `http://otinventory.com:18273` 접속 시 ERR_NAME_NOT_RESOLVED
- **원인**: DNS 변경 후 전파 시간 필요 (최대 24시간)
- **해결**: 기다리거나 https://www.whatsmydns.net 에서 전파 상태 확인

### 2. Page Rules와 redirect_server.py 충돌
- **증상**: 리디렉션이 이상하게 동작
- **원인**: 두 가지 리디렉션 방법이 동시에 작동
- **해결**: 하나만 선택 (Page Rules 권장)

### 3. Cloudflare IP 화이트리스트 문제
- **증상**: 접속 시 403 Forbidden
- **원인**: 보안 설정이 너무 엄격
- **임시 해결**: `server.py`에서 `CLOUDFLARE_IP_WHITELIST_ENABLED = False`로 변경
