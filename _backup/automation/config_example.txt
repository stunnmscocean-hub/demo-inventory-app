xlsx_watcher.c 파일 상단의 설정 부분을 수정하세요:

// ========================================
// 기본 설정
// ========================================
#define WEB_PORT "8080"              // 사용할 포트 번호

#define ENABLE_PUBLIC_ACCESS 1       // 0 = localhost만
                                     // 1 = 외부 접근 허용

#define ENABLE_DDNS 0                // 0 = 비활성화
                                     // 1 = 동적 DNS 자동 업데이트

#define DDNS_UPDATE_URL ""           // FreeDNS Update URL 입력

#define DDNS_UPDATE_INTERVAL_SEC 600 // 업데이트 주기 (초)

  사용 시나리오
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📍 시나리오 1: 로컬에서만 사용 (기본값)
------------------------------------------
#define ENABLE_PUBLIC_ACCESS 0
#define ENABLE_DDNS 0

→ http://localhost:8080 으로만 접근 가능


📍 시나리오 2: 같은 네트워크에서 접근
------------------------------------------
#define ENABLE_PUBLIC_ACCESS 1
#define ENABLE_DDNS 0

→ http://192.168.x.x:8080 으로 접근 가능
→ 모바일, 다른 PC에서 접근 가능 (같은 WiFi)


📍 시나리오 3: 인터넷 어디서나 접근 (추천)
------------------------------------------
#define ENABLE_PUBLIC_ACCESS 1
#define ENABLE_DDNS 1
#define DDNS_UPDATE_URL "https://freedns.afraid.org/dynamic/update.php?YOUR_TOKEN"

→ http://mystock.mooo.com:8080 으로 접근 가능
→ 외부 인터넷에서도 접근 가능
→ IP 변경 시 자동 업데이트

  동적 DNS 설정 방법 (FreeDNS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://freedns.afraid.org 접속 및 회원가입

2. "Subdomains" → "Add" 클릭
   - Type: A
   - Subdomain: 원하는 이름 (예: mystock)
   - Domain: 선택 (예: mooo.com)
   - 결과: mystock.mooo.com

3. "Dynamic DNS" 메뉴 클릭
   - "Direct URL" 링크 복사
   - 예: https://freedns.afraid.org/dynamic/update.php?abcd1234...

4. 복사한 URL을 코드의 DDNS_UPDATE_URL에 입력

5. ENABLE_DDNS를 1로 변경

6. 재컴파일:
   gcc xlsx_watcher.c mongoose.c -o xlsx_watcher.exe -lws2_32 -lcomctl32 -mwindows

  공유기 포트 포워딩 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

외부에서 접근하려면 공유기 설정이 필요합니다:

1. 공유기 관리자 페이지 접속
   - 주소: 192.168.0.1 또는 192.168.1.1
   - 제조사마다 다를 수 있음

2. "포트 포워딩" 또는 "가상 서버" 메뉴 찾기

3. 새 규칙 추가:
   ┌──────────────┬────────────────┐
   │ 외부 포트    │ 8080           │
   │ 내부 IP      │ (현재 PC IP)   │
   │ 내부 포트    │ 8080           │
   │ 프로토콜     │ TCP            │
   └──────────────┴────────────────┘

4. PC IP 확인:
   cmd> ipconfig
   → IPv4 주소 확인 (예: 192.168.0.105)

  Windows 방화벽 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PowerShell을 관리자 권한으로 실행 후:

netsh advfirewall firewall add rule name="Stock Check Server" dir=in action=allow protocol=TCP localport=8080

→ 8080 포트 인바운드 허용

  접근 테스트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 로컬 테스트:
   → http://localhost:8080

2. 같은 네트워크 테스트:
   → http://192.168.x.x:8080
   → 모바일에서 WiFi 연결 후 테스트

3. 외부 테스트:
   → http://[공인IP]:8080
   → 모바일 데이터로 접속 테스트
   → 또는 https://www.yougetsignal.com/tools/open-ports/

4. 도메인 테스트 (DDNS 사용 시):
   → http://mystock.mooo.com:8080

  문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "사이트에 연결할 수 없음"
   → 방화벽 설정 확인
   → 포트 포워딩 설정 확인
   → 프로그램 실행 확인

❌ "공인 IP를 가져올 수 없습니다"
   → 인터넷 연결 확인
   → 잠시 후 자동 재시도됨

❌ "포트 8080 사용 중?"
   → 다른 프로그램이 8080 포트 사용 중
   → WEB_PORT를 다른 번호로 변경 (예: 8081)

❌ "DDNS 업데이트 실패"
   → DDNS_UPDATE_URL 확인
   → 인터넷 연결 확인
   → FreeDNS 토큰 만료 확인

⚠️ 주의: 외부에 공개할 때는 다음을 고려하세요

1. 필요한 경우에만 ENABLE_PUBLIC_ACCESS = 1
2. 강한 비밀번호 사용 (향후 인증 기능 추가 예정)
3. HTTPS 사용 권장 (민감한 데이터의 경우)
4. 정기적으로 로그 확인
5. 의심스러운 접속은 차단
